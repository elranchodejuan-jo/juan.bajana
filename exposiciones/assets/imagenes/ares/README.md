# Fotografías del caso Ares

Fotografías reales aportadas por el tutor para la tesina, presentación y exposición web. No se han generado imágenes ni modificado el contenido visual; se conservaron las proporciones y se redujo tamaño/comprimió a WebP.

- `ares-actual.webp`: Ares en automóvil, posterior al tratamiento según el tutor.
- `ares-examen.webp`: examen físico con estudiantes; fecha no corroborada.
- `heces-a.webp`, `heces-b.webp`, `heces-c.webp`: tres fotografías anteriores al tratamiento. Las letras no indican un orden temporal. Las imágenes no confirman un agente causal ni sangrado por sí solas.

No se incluyen documentos con contacto del tutor ni tablas que mezclan datos de ejemplo con registros reales sin identificación.
